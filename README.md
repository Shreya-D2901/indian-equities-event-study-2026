# indian-equities-event-study-2026
Excel event study of Indian stocks around 2026 war and oil-shock events using Excel
# Event Study: 2026 War & Oil Shock Impact on Indian Equities

An Excel analysis of how ONGC, HAL, TCS, BPCL and GOLDBEES reacted to
five major 2026 events, measured against the Nifty and USD/INR.

## Events studied
War begins, ceasefire announced, Brent $111 / rupee record low,
renewed US strikes, Sensex 2026 low.

## Method
- Post-event returns (5 trading days; 1 day for the last event)
- Abnormal return = stock return minus Nifty return
- Daily returns, annualised volatility, beta and correlation

## Key findings
- HAL averaged about +6% abnormal return around events
- BPCL fell about 14% after war onset and rebounded about 12% after the ceasefire

## Files
- `Portfolio_project.xlsx`: Prices, Events, Macro, Summary, Abnormal, Returns sheets

## Limitations
Only 4 events in the average, no significance testing, and simple
market-adjusted returns. Planned: portfolio weights, market model, charts.
